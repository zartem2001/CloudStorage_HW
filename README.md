# Облачное хранилище (Cloud Storage)

## 📋 Описание проекта

REST-сервис для загрузки, хранения и управления файлами пользователя. 
Реализован как **дипломный проект** курса «Java-разработчик» Нетологии.

Сервис предоставляет REST API для интеграции с готовым FRONT-приложением (Vue.js), 
поддерживает авторизацию по токену, загрузку/скачивание/переименование/удаление 
файлов и вывод списка файлов пользователя.

## 🎯 Цель проекта

Отработать полный цикл разработки backend-приложения:
- Проектирование REST API по YAML-спецификации;
- Авторизация через токены (`auth-token`);
- Работа с базой данных (PostgreSQL) через Spring Data JPA;
- Хранение файлов на диске (файловая система);
- Написание unit-тестов (JUnit + Mockito) и интеграционных тестов (Testcontainers);
- Запуск через Docker и Docker Compose;
- Настройка CORS для интеграции с FRONT.

## 🛠️ Используемые технологии

- Java 17+
- Spring Boot
- Spring Web MVC
- Spring Data JPA + Hibernate
- PostgreSQL
- BCrypt (хэширование паролей)
- JUnit 5 + Mockito
- Testcontainers
- Docker / Docker Compose
- Maven
- Lombok
